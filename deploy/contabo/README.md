# გადატანა Contabo-ზე (ramaz.ge)

ძველი საიტი (PythonAnywhere) მუშაობს მანამ, სანამ ახალს ბოლომდე არ შეამოწმებთ.
პაროლებს არავის გაუგზავნოთ ჩატში — ყველაფერი თქვენს კომპიუტერზე / სერვერზე რჩება.

## 1. სერვერის ყიდვა

contabo.com → **Cloud VPS** → უმცირესი (Cloud VPS 10 ან მსგავსი) — სრულიად საკმარისია.
- **Region:** European Union (Germany)
- **Image:** **Ubuntu 24.04**
- **Login:** დააყენეთ root-ის ძლიერი პაროლი (ჩაიწერეთ, არავის მისცეთ)
- დამატებითი სერვისები (backup, panel და ა.შ.) არ გჭირდებათ: ასლს საიტი თავად აკეთებს ყოველდღე.

ყიდვის შემდეგ ელფოსტით მოვა სერვერის **IP მისამართი** (მაგ. `123.45.67.89`).

## 2. დომენის მიბმა (ramaz.ge → სერვერი)

იქ, სადაც დომენი იყიდეთ → DNS ჩანაწერები → დაამატეთ ორი **A** ჩანაწერი:

| Type | Name / Host | Value |
|---|---|---|
| A | `@` (ან ცარიელი) | სერვერის IP |
| A | `www` | სერვერის IP |

ცვლილებას 10 წუთიდან რამდენიმე საათამდე სჭირდება.

## 3. სერვერზე დაკავშირება

Windows: **Start → PowerShell** (Mac: Terminal) და:

```bash
ssh root@სერვერის-IP
```

პირველად იკითხავს „Are you sure…“ — ჩაწერეთ `yes`, მერე root-ის პაროლი (ჩაწერისას არ ჩანს — ნორმალურია).

## 4. საიტის დაყენება (ერთი ბრძანება, ~10 წუთი)

სერვერზე (სადაც ელფოსტა — თქვენი ელფოსტა, HTTPS სერთიფიკატის შეტყობინებებისთვის):

```bash
apt-get update && apt-get install -y git && git clone -b claude/dazzling-cerf-tp4313 https://github.com/apkhadzeangio/New_MedF.git /root/New_MedF && bash /root/New_MedF/deploy/contabo/setup.sh ramaz.ge თქვენი@ელფოსტა
```

ბოლოს უნდა ეწეროს `Done: https://ramaz.ge`. თუ დაწერა „HTTPS certificate failed“ —
DNS ჯერ არ გავრცელებულა (ნაბიჯი 2); ცოტა ხანში გაუშვით ის ბრძანება, რომელსაც თავად გიჩვენებთ.

## 5. მონაცემების წამოღება PythonAnywhere-იდან

PythonAnywhere → **Consoles → Bash** (ბაზის პაროლი იგივეა, რაც `.env`-ში):

```bash
mysqldump -u medf -h medf.mysql.pythonanywhere-services.com --no-tablespaces 'medf$MDF' > ~/medf-pa.sql
```

```bash
cd ~ && tar -czf medf-media.tar.gz medf-media
```

PythonAnywhere → **Files** → ჩამოტვირთეთ თქვენს კომპიუტერში ორივე ფაილი: `medf-pa.sql` და `medf-media.tar.gz`.

## 6. მონაცემების ატვირთვა ახალ სერვერზე

თქვენს კომპიუტერზე, **ახალ** PowerShell ფანჯარაში, იმ საქაღალდიდან, სადაც ფაილები ჩამოიტვირთა (ჩვეულებრივ `cd Downloads`):

```bash
scp medf-pa.sql medf-media.tar.gz root@სერვერის-IP:/root/
```

მერე სერვერის ფანჯარაში:

```bash
bash /srv/medf/app/deploy/contabo/import.sh /root/medf-pa.sql /root/medf-media.tar.gz
```
